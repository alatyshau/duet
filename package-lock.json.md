# package-lock.json

ЧТО: Точный снимок (lockfile) всех установленных npm-зависимостей.

ЗАЧЕМ: Гарантировать что `npm install` установит **идентичные** версии пакетов на любой машине.

КТО ИСПОЛЬЗУЕТ: `npm` автоматически при каждом `npm install`.

---

## Важно

**Этот файл генерируется автоматически.** Не редактируй вручную.

- Создаётся/обновляется при `npm install`
- Содержит точные версии ВСЕХ зависимостей (включая зависимости зависимостей)
- Без него `npm install` может установить разные версии на разных машинах

---

## FAQ

### Почему файл такой огромный?

Потому что содержит ВСЮ иерархию зависимостей. Один пакет тянет десятки других, те — ещё десятки. В итоге тысячи записей.

### Нужно ли коммитить в git?

**Да.** Это гарантирует воспроизводимость сборки.

Без lockfile:
- Ты: `npm install` → получил `lodash@4.17.21`
- Коллега через месяц: `npm install` → получил `lodash@4.17.25`
- Баг который у тебя не было → появился у коллеги

С lockfile: все получают одинаковые версии.

### Можно ли удалить?

Можно, но не нужно. При следующем `npm install` создастся заново, но версии могут отличаться от тех что были.

### Конфликты при merge?

Частая проблема. Решение:
```bash
# Удалить lockfile, переустановить
rm package-lock.json
npm install
```

Или использовать `npm ci` (clean install) — устанавливает строго по lockfile.
