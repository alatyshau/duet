# Библиотека ролей AI-агентов

ЧТО: Коллекция ролей для различных AI-ассистентов в проекте.
ЗАЧЕМ: Стандартизация поведения AI, разделение ответственности.
КТО ИСПОЛЬЗУЕТ: Claude Code, Gemini Code Assist, другие AI.

---

## Роли

| Роль | Файл | Назначение |
|------|------|------------|
| Principal | `principal.md` | Архитектор экосистемы репозитория |
| Keeper | `keeper.md` | Хранитель документации |
| L6 Engineer | `l6-engineer.md` | Senior разработчик (имплементация) |
| Tech Lead Shadow | `tech-lead-shadow.md` | Ревьюер кода (наблюдение) |

---

## Запуск Principal

### Вариант 1: Базовый

```
Привет. Действуй согласно своей роли в @.ai/roles/principal.md

# Задача на сегодня

```

### Вариант 2: Нарезка батчей для Кипера

**Principal обновляет backlog и нарезает батчи:**
```
Роль: principal

Запусти: python packages/ai-roles/scripts/backlog_updater.py
Посмотри keeper_state.json → backlog.
Разбей на батчи (≤3 секций или ≤5 файлов).
Для каждого батча дай готовый промпт по шаблону из .ai/roles/README.md → "Шаблон промпта для Keeper".
```


## Запуск Keeper

### Вариант 1: Последовательно (один Keeper)

```
Роль: keeper

Действуй по алгоритму, и добросовестно и в полной мере выполняй принцип "Шаг назад" для каждого выбранного тобой батча!
```

Keeper сам управляет backlog: запускает `backlog_updater.py`, выбирает батчи, обрабатывает, фиксирует.

### Вариант 2: Параллельно (несколько окон)

Батчи нарезает Principal (см. "Нарезка батчей для Кипера"). Пользователь открывает несколько окон.

**Шаблон промпта для Keeper:**
```
Ты выполняешь роль Keeper.

## Инструкции
Прочитай: .ai/roles/keeper.md
Следуй алгоритму начиная с Шага 4 (Выполнение). Добросовестно и в полной мере выполняй принцип "Шаг назад" для батча!

## Контекст
Шаги 1-3 уже выполнены. Твой батч:
- [файл 1]
- [файл 2]
- ...

## Ограничения
- НЕ запускай backlog_updater.py в начале (уже запущен)
- `--done` ТОЛЬКО после моего явного одобрения! (иначе mtime-баг: файлы с временем изменения > updated_at снова попадут в backlog)
- НЕ выполняй Шаг 7 (следующий батч) — только твой батч
```
