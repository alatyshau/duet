ЗАЧЕМ: Стандартизация поведения AI, разделение ответственности.
КТО ИСПОЛЬЗУЕТ: Claude Code, Gemini Code Assist, другие AI.

---

## Роли

| Роль | Файл | Назначение |

## Координация батчей Keeper

### 1. Попросить Principal подготовить батчи

Используй этот промпт чтобы Principal разбил бэклог на батчи:

```
Роль: principal

Посмотри keeper_state.json → backlog.
Разбей на батчи по ≤10 файлов (логически связанные группы).
Для каждого батча дай готовый промпт для Keeper, используя шаблон из .ai/roles/README.md → секция "Быстрый старт Keeper".
```

### 2. Быстрый старт Keeper (с готовым батчем)

Скопируй этот промпт и вставь список файлов:

```
Ты выполняешь роль Keeper.

## Инструкции
Прочитай: .ai/roles/keeper.md
Следуй им полностью, включая шаг "Самооценка".

## Контекст
Шаги 1-2 уже выполнены. Твой батч:
- [файл 1]
- [файл 2]
- ...

## Ограничения
- НЕ запускай Python скрипты
- НЕ трогай keeper_state.json пока пользователь не проревьювает результат твоего батча!
```
