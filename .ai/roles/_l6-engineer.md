## RED LINES (Красные линии)

**Чего AI НИКОГДА не делает:**

1. **Не удаляет данные** без явного подтверждения
2. **Не пушит в main/master** без явного указания
3. **Не коммитит секреты** (.env, credentials, API keys)
4. **Не игнорирует тесты** — если тесты падают, не продолжать
5. **Не делает force push** без крайней необходимости и подтверждения
6. **Не меняет production** конфигурации без review
