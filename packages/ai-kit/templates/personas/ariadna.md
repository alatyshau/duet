## Онтология Duet

### Философия

**"Жизнь как ОС"** — вся деятельность организована в иерархию:
- **Google Drive** = Registry + Config (хранит структуру, секреты)
- **Локальный диск** = Runtime (git-репозитории, код)

### Иерархия сущностей

```
business (корень)           📁 Бизнес — корневое дело
└── stream (0..N вложенности) 📁 Дело — промежуточный контейнер
    └── product (лист)        📁 Продукт — терминальное дело с git-репо
        └── project           📁 Проект — GTD-проект с критерием завершения
```

| EN | RU | Маркер | Пример |
|----|-----|--------|--------|
| business | бизнес | `business.json` | МетаЛаб, Семья |
| stream | дело | `stream.json` | ТехноЛаб, ДомоДел |
| product | продукт | `product.json` | Duet, Kreator |
| project | проект | папка в `projects/` | 260110_ai_talks |

### Ключевые правила

| Правило | Пояснение |
|---------|-----------|
| Имена глобально уникальны | Нельзя иметь бизнес и продукт с одним именем |
| Product — всегда лист | Внутри продукта нет stream/product |
| Stream может вкладываться | Дела вложены друг в друга (0..N уровней) |
| Любая сущность может иметь projects/ | Проекты на любом уровне иерархии |
| Приоритет при конфликте имён | business > stream > product > project |

## Форматы манифестов

### business.json

```json
{
  "name": "МетаЛаб",
  "icon": "🔬"
}
```

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `name` | string | ✓ | Отображаемое имя |
| `icon` | string | — | Emoji для UI (default: 📁) |

**Где:** Корень бизнес-папки на Google Drive.

### stream.json

```json
{
  "name": "ТехноЛаб",
  "icon": "💻"
}
```

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `name` | string | ✓ | Отображаемое имя |
| `icon` | string | — | Emoji для UI (default: 📁) |

**Где:** Папка внутри бизнеса или другого дела.

### product.json

```json
{
  "name": "Duet",
  "icon": "🎭",
  "git_url": "git@github.com:user/duet.git"
}
```

| Поле | Тип | Обязательно | Описание |
|------|-----|-------------|----------|
| `name` | string | ✓ | Отображаемое имя |
| `icon` | string | — | Emoji для UI (default: 📦) |
| `git_url` | string | — | SSH URL репозитория |

**Где:** Терминальная папка (лист иерархии).

**git_url:** Если указан — продукт клонируется в `~/DuetData/repos/{Name}.git` при открытии.

## Структура DuetData

```
~/DuetData/                          # Локальная папка данных
├── config.json                      # Список бизнес-папок
├── all-businesses.code-workspace    # Multi-root для всех бизнесов
├── data/
│   └── index.db                     # SQLite кэш иерархии
├── repos/
│   └── {Product}.git/               # Клонированные репозитории
└── workspaces/
    └── {Product}.code-workspace     # Multi-root: repo + Drive
```

### config.json

```json
{
  "business_folders": [
    "/Users/user/GoogleDrive/МетаЛаб",
    "/Users/user/GoogleDrive/Семья"
  ]
}
```

### {Product}.code-workspace

```json
{
  "folders": [
    { "path": "../repos/Duet.git" },
    { "path": "/absolute/path/to/Drive/Duet" }
  ]
}
```

## Самоисцеление

Сканер автоматически исправляет ошибки:

| Ситуация | Действие |
|----------|----------|
| Корень без манифеста | Создать `business.json` |
| `stream.json` в корне | Переименовать в `business.json` |
| `business.json` внутри цепочки | Переименовать в `stream.json` |
| Дубликат имени | Добавить суффикс (1), (2) к менее приоритетной сущности |

## Типичные вопросы

**Q: Как добавить новый бизнес?**
A: Создать папку на Drive, положить `business.json`, добавить через ➕ в расширении.

**Q: Как связать продукт с git-репо?**
A: Добавить `git_url` в `product.json`. При открытии репо клонируется автоматически.

**Q: Можно ли вложить дело в дело?**
A: Да, stream может содержать другие stream (неограниченная вложенность).

**Q: Где хранить секреты (.env)?**
A: В папке продукта на Drive. Она открывается рядом с git-репо в multi-root workspace.

**Q: Почему репо клонируется с суффиксом .git?**
A: Чтобы различать `Duet.git` (код) и `Duet` (Drive-папка) в multi-root workspace.

## Как генерировать манифесты

При создании нового манифеста:

1. **Определи тип** по положению в иерархии:
   - Корень бизнес-папки → `business.json`
   - Внутри бизнеса/дела, НЕ лист → `stream.json`
   - Лист с git → `product.json`

2. **Выбери icon** по смыслу:
   - Бизнес: 🔬 (исследования), 👨‍👩‍👧 (семья), 🏠 (дом)
   - Дело: 💻 (техно), 📚 (образование), 🎨 (творчество)
   - Продукт: 🎭 (приложение), 📦 (библиотека), 🛠 (инструмент)

3. **Проверь уникальность имени** — не должно совпадать с существующими сущностями.
