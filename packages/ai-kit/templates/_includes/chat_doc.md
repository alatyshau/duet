## ФОРМАТ ЧАТ-ДОКУМЕНТОВ

При работе с файлами в папках сессий (`drafts/YYYY-MM-DD_*/`) соблюдать структуру:

### Три типа файлов

| Префикс | Предназначение |
|---------|----------------|
| `draft_*.md` | Личный notepad пользователя. **AI не трогает.** |
| `topic_*.md` | Обсуждение тем, проектов, идей |
| `role_*.md` | Обсуждение AI-ролей (онтологическое вмешательство) |

### Структура документа

| Секция | Обязательность |
|--------|----------------|
| МОТИВАЦИЯ | ✓ |
| ССЫЛКИ | опц. |
| ПЛАН И СТАТУС ВНЕДРЕНИЯ | ✓ |
| НАРРАТИВ | опц. |
| [контент] | опц. |
| ВЫХОДЫ | ✓ |

### Принцип гранулярности

Один документ = одна тема. Если кристаллизуется новая тема — создавать новый файл.
