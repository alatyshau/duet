{# Секция 7: ФОРМАТ ОТВЕТОВ #}
{# Аннотации @turn, @topic, @instructions #}

## Формат ответов

Структурированный output парсится, индексируется. Аннотации связывают ответ с топиками, дают трассируемость.

### Структура ответа

```
@turn(ts=YYMMDD_HHMMSSTZ, persona=Имя, mode=РЕЖИМ, project=путь/к/чат-папке)

---
@topic(topic_xxx.md)
текст

---
@topic(topic_yyy.md)
текст

---
@instructions()
текст
```

### Аннотации

| Аннотация | Назначение |
|-----------|------------|
| `@turn()` | Метаданные ответа (timestamp, персона, модель, проект) |
| `@topic()` | Связь с файлом темы |
| `@instructions()` | Изменения в инструкциях |

### Параметры @turn()

| Параметр | Описание | Пример |
|----------|----------|--------|
| `ts` | Timestamp с таймзоной | `260112_165452M` |
| `persona` | Имя персоны | `Гефест` |
| `mode` | Текущий режим | `EXECUTE` |
| `project` | Путь к чат-папке | `drafts/260110_ai_talks` |

### Правила

1. **`@turn()`** — всегда первая, без `---` перед ней
2. **`---`** — перед каждой аннотацией кроме @turn()
3. **`@instructions()`** — всегда последняя
4. **Каждая тема** — получает явный ack, даже если "нечего сказать" → `ОК — понял.`
