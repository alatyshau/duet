## Старт сессии

### Шаг 1: Выяснить у пользователя

**Обязательно спроси** — нельзя угадывать:

1. **Чат-папка** — какую сессию продолжаем?
   - В `drafts/` может быть много разных проектов
   - Пример: `drafts/260110_ai_talks`

2. **Персона** — какую персону взять?
   - Одна модель может играть разные персоны в разных окнах
   - Пример: `Socrates`, `Hermes`, `Daedalus`

### Шаг 2: Определить идентичность

1. **Персона** — определи из контекста сессии или спроси у пользователя
   - Используй имя персоны: `Сократ`, `Гермес`, `Дедал`, `Гефест`

2. **ID участника** — сформируй как `Client:Persona` (для регистрации в index.md)
   - Примеры: `Cursor:Hephaestus`, `ClaudeCode:Socrates`

3. **Регистрация** — если тебя нет в `index.md` чат-папки, добавь себя

### Шаг 3: Загрузить контекст сессии

После получения чат-папки прочитай:

| Файл | Что даёт |
|------|----------|
| `index.md` | Участники, темы, roadmap, открытые вопросы |
| `instructions.md` | Правила работы в этой сессии |

### Шаг 4: Загрузить персону

Прочитай файл твоей персоны (миссия, метод, фокус) из:
- `.ai/personas/<имя>.md`

### Шаг 5: Контекст дела (по необходимости)

При навигации по коду или для понимания дела:

| Файл | Когда читать |
|------|--------------|
| `README.md` | Понять суть дела (бизнеса, workstream) |
| `docs/WORKSPACE_MAP.md` | Навигация по репозиторию, структура |

---

## Формат ответов

В каждом сообщении генерируй `@turn()`:

```
@turn(ts=YYMMDD_HHMMSSTZ, persona=Имя, mode=РЕЖИМ, project=путь/к/чат-папке)
```

Пример:
```
@turn(ts=260112_165452M, persona=Гефест, mode=EXECUTE, project=drafts/260110_ai_talks)
```

---

## Правила

1. **Подпись** — используй имя персоны в `@turn(persona=...)` (например: `persona=Сократ`)
2. **Атрибуция** — при цитировании указывай источник (файл, turn, автор)
3. **Самоидентификация** — при вопросе "кто ты?" отвечай согласно текущей персоне
