{# Режимы работы агента — определение и переключение #}

## Режимы работы

Режим отвечает на вопрос: **"Что сейчас происходит и что агенту разрешено?"**

### Общие режимы

| Режим | Фокус | Контекст | Что разрешено | Что делает |
|-------|-------|----------|---------------|------------|
| **DIALOGUE** | index.md | Лёгкий | Чат-папка | Рассуждаем, накапливаем контекст |
| **PLANNING** | Один topic-файл | **Глубокий** | Чат-папка | Формулируем план |
| **EXECUTE** | Один шаг | **Глубокий** | Код, конфиги | Реализация по плану |
| **SECRETARY** | Все topic-файлы | Широкий | Чат-папка | Архивация чата в файлы |
| **COMMENTARY** | Указанные файлы | По запросу | Чат-папка | Комментирование файлов |
| **REVIEW** | Topic-файл + результаты | **Глубокий** | Чат-папка | Ревью работы другого агента |

### Проприетарные режимы (в роли)

| Режим | Роль-владелец | Кратко |
|-------|---------------|--------|
| **KEEPER** | Hermes | Ведение документации — см. role-файл |
| **TRICKSTER** | Loki | Провокация, альтернативы — см. role-файл |

> Общие режимы знают все роли. Проприетарные — детально знает только роль-владелец.

---

## Правила

### Начало сессии = DIALOGUE

Каждая новая сессия начинается в режиме DIALOGUE, даже если в файлах есть WIP-шаги.

**Почему:** новая сессия = потеря контекста чата. Автоматическое продолжение EXECUTE опасно.

**Поведение при старте с WIP:**
```
Agent: "С прошлой сессии остался WIP-шаг в topic_xxx.md. Продолжить?"
User: "Да" → EXECUTE
User: "Нет" → остаёмся в DIALOGUE
```

### mode= в @turn()

В @turn() указывай только имя роли. Пример:
```
@turn(ts=260112_165452M, agent=Гефест, mode=EXECUTE, project=drafts/260110_ai_talks)
```

### Какие файлы читать в каждом режиме

| Режим | Что читать |
|-------|------------|
| **DIALOGUE** | `index.md` (обязательно), topic-файлы по мере упоминания |
| **PLANNING** | Весь topic-файл: секции НАРРАТИВ + ВЫХОДЫ + ПЛАН ВНЕДРЕНИЯ |
| **EXECUTE** | Весь topic-файл + текущий шаг из ПЛАН ВНЕДРЕНИЯ |
| **SECRETARY** | `index.md` + заголовки всех topic-файлов |
| **REVIEW** | Весь topic-файл + созданные артефакты (файлы кода, конфигов) |

**Правило для PLANNING, EXECUTE, REVIEW:** перед началом работы прочитай topic-файл целиком. Шаг опирается на спецификацию в ВЫХОДАХ, решения в НАРРАТИВ влияют на интерпретацию.

### Execute только с планом

```
Запрос на действие вне чат-папки
        │
        ▼
   Есть ПЛАН ВНЕДРЕНИЯ?
        │
   НЕТ──┴──ДА
    │       │
    ▼       ▼
СТОП    /next → Execute
    │
    ▼
Создать топик (если нет)
    │
    ▼
Сформулировать ПЛАН ВНЕДРЕНИЯ
    │
    ▼
"Это то что ты хочешь?"
```

### Разделение зон

| Зона | Режимы | Правила |
|------|--------|---------|
| **Чат-папка** | DIALOGUE, PLANNING, SECRETARY, COMMENTARY, REVIEW | Свободнее, накопление контекста |
| **Репозиторий** | EXECUTE | Только по плану, только после /next |

## Философия режима DIALOGUE

**Обязательно (index.md):**
- Удерживать внимание на index.md
- Вовремя создавать новые темы
- Идентифицировать всё (темы, участников)

**Приветствуется (topic-файлы):**
- Писать в НАРРАТИВ
- Обновлять МОТИВАЦИЯ
- Обновлять начало ПЛАНА ВНЕДРЕНИЯ (цели, критерии)

**Но не обязательно** — для полного переноса из чата в файлы есть режим SECRETARY.
