{# State machine шагов в режиме EXECUTE #}

## State machine шагов

Каждый шаг в ПЛАН ВНЕДРЕНИЯ проходит через 4 статуса:

```
TODO ──/next──► WIP ──(агент)──► IN_REVIEW ──/done──► DONE
                                     │
                                     └──(правки по замечаниям)──┘
```

### Статусы

| Статус | Владелец | Агент может |
|--------|----------|-------------|
| `TODO` | User | ❌ Ждать `/next` |
| `WIP` | Agent | ✅ Работать |
| `IN_REVIEW` | User | ⛔️ РУКИ ПРОЧЬ (Только по запросу) |
| `DONE` | — | ❌ Закрыто |

> **IN_REVIEW** означает, что мяч на стороне пользователя. Агент **ЖДЕТ** и ничего не делает без явной просьбы.

---

## Команды (explicit triggers)

| Команда | Действие | Переход |
|---------|----------|---------|
| `/next` | Начать следующий TODO-шаг | TODO → WIP |
| `/done` | Закрыть текущий IN_REVIEW-шаг | IN_REVIEW → DONE |
| `/done-next` | Закрыть И начать следующий | IN_REVIEW → DONE + TODO → WIP |

---

## Критические правила

### 1. `/done` ≠ `/next`

Закрытие шага **НЕ даёт** разрешения начать следующий.

```
User: /done
Agent: "Шаг N закрыт. Начать шаг N+1?"  ← ждём явного разрешения
```

### 2. Междометия ≠ команда

**Междометия** ("хорошо", "ок", "круто", "понял") — это feedback, НЕ команда.

```
User: "Хорошо"
Agent: "Могу начать выполнение шага N?"  ← запросить подтверждение
```

**Явные триггеры:**
- `/next` — начать шаг
- "Да, выполняй" — начать шаг
- "Да" (в контексте вопроса о начале) — начать шаг

### 3. WIP обычно один

- Агент фокусируется на одном WIP-шаге
- IN_REVIEW может быть много одновременно
- Можно начать следующий шаг до закрытия предыдущего IN_REVIEW

---

## Типичное состояние плана

```
### Шаг 1 — DONE
### Шаг 2 — IN_REVIEW
### Шаг 3 — IN_REVIEW
### Шаг 4 — WIP ← агент здесь (обычно один)
### Шаг 5 — TODO
```

---

## Омонимия: REVIEW (режим) ≠ IN_REVIEW (статус)

| Термин | Контекст | Значение |
|--------|----------|----------|
| **REVIEW** | Режим агента | Что агент делает: ревью работы другого агента |
| **IN_REVIEW** | Статус шага | Шаг выполнен агентом, ждёт проверки пользователем |

> В state machine шагов используем `IN_REVIEW`, не `REVIEW`.
