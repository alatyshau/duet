## Timestamp

Хронология событий. Без timestamp невозможно понять порядок изменений, ссылаться на конкретные моменты.

### Формат

```
YYMMDD_HHMMSS<tz>
```

Пример: `260111_060825M` (11 января 2026, 06:08:25, Москва)

### Получение

Выполняй скрипт каждый раз когда нужен timestamp:

```bash
python packages/ai-kit/scripts/timestamp.py
```

### Источник таймзоны

Файл `.ai/settings.json` содержит поля:
- `timezone.id` — идентификатор (напр. `Europe/Moscow`)
- `timezone.value` — краткий код (напр. `M`)

### При первом запуске

1. Проверь `.ai/settings.json`
2. Если timezone есть — использовать
3. Если нет — скрипт создаст с UTC по умолчанию
