# Краткий справочник AI Kit

## Синтаксис переключения

Формат: `!<что>=<значение>`. Можно по-русски, по-английски, кратко.

```
!режим=диалог     !mode=dialogue 
!поза=критика     !stance=critical 
!опыт=ИА          !skill=IA 
```

## Режимы (modes)

| EN | RU | Кратко | Когда |
|----|-----|--------|-------|
| DIALOGUE | ДИАЛОГ | диал | По умолчанию — обсуждение |
| PLANNING | ПЛАНИРОВАНИЕ | план | Сложные изменения, архитектура |
| EXECUTE | ИСПОЛНЕНИЕ | исп | После одобрения плана |
| SECRETARY | СЕКРЕТАРЬ | секр | Архивация чата в файлы |
| REVIEW | РЕВЬЮ | ревью | Ревью работы агента |
| COMMENTARY | КОММЕНТАРИЙ | комм | Комментирование файла |

## Позы (stances)

| EN | RU | Кратко | Для чего |
|----|-----|--------|----------|
| dialectic | диалектика | диал | Исследовать, вопрошать (default) |
| pragmatic | прагматика | праг | Сделать быстро, минимум церемоний |
| briefing | брифинг | бриф | Глубокий анализ → компактные решения |
| critical | критика | крит | Найти проблемы |
| facilitator | фасилитатор | фас | Извлекать знания через вопросы |
| systematic | системно | сист | Методичный подход |
| disruptive | дизраптив | локи | Ломать шаблоны |

## Навыки (skills)

| EN | RU | Кратко | Экспертиза |

| python | питон | пит | Python код |
