# Гайд по выбору позы (Stance)

## По умолчанию: dialectic

Если не уверен — не указывай. Агент будет исследовать, не торопясь с выводами.

## Когда переключать

| Тебе нужно... | Используй | Пример |
|---------------|-----------|--------|
| Исследовать варианты | `!stance=dialectic` | Архитектурные решения |
| Просто сделать, быстро | `!stance=pragmatic` | Исправить опечатку |
| Решения с рекомендациями | `!stance=briefing` | "Что нам делать?" |
| Найти проблемы | `!stance=critical` | Ревью кода, аудит |
| Помочь разобраться | `!stance=facilitator` | "Задавай мне вопросы" |

## Краткая справка

```
dialectic   — исследуй, вопрошай, держи открытым
pragmatic   — решай сейчас, минимум церемоний
briefing    — глубокий анализ → компактные решения
critical    — найди что не так
facilitator — извлекай знания через вопросы
```

## Комбинация с навыками

```
!stance=briefing !skill=instructions-architect
!stance=critical !skill=typescript
```

Skill = предметная экспертиза (что знаешь)
Stance = режим мышления (как подходишь)

## Советы

- **briefing** подразумевает глубокую работу — агент читает всё, ты читаешь только итог
- **facilitator** требует повторения — агент по умолчанию решает, напоминай ему спрашивать
- **pragmatic** для ясных задач — не используй когда требования размыты
