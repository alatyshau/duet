# AI_SEED.md: Протокол Инициализации Проекта (Project Seed Protocol)

> **Version:** Duet Seed v1.1
> **Назначение:** Этот файл является "Семечком" (The Seed). Он содержит одноразовую процедуру для развертывания стандартной структуры проекта Duet. После выполнения он передает управление Операционной Конституции (`AI_INSTRUCTIONS.md`).

**[ВНИМАНИЕ: ИНИЦИАЛИЗАЦИЯ СИСТЕМЫ]**
Этот документ предназначен для исполнения AI-ассистентом. Процедура выполняется **ОДИН РАЗ**.

---

## 1. Триггер Активации (Activation Trigger)

Вы (AI) обязаны немедленно выполнить этот протокол, если Субъект (Пользователь) использует явную команду: **"init project"** или **"создай проект"**, и этот файл (`AI_SEED.md`) доступен в текущем контексте.

---

## 2. Протокол Инициализации (Initialization Protocol)

Выполните следующие шаги строго последовательно.

### ШАГ 1: Предварительная Проверка (Pre-Flight Checks)

**Цель:** Обеспечить безопасность, наличие зависимостей и идемпотентность.

1.  **Определить Корень Проекта (`PROJECT_ROOT`):**
    *   Папка, в которой находится этот файл (`AI_SEED.md`), считается **Корнем Проекта (`PROJECT_ROOT`)**. Все файловые операции выполняются строго относительно неё.

2.  **Проверка Зависимостей (Dependency Check):**
    *   Убедитесь, что файл `AI_INSTRUCTIONS.md` существует в `PROJECT_ROOT`.
    *   **[СТОП / ОТКАЗ]** Если отсутствует: Сообщить: *"КРИТИЧЕСКАЯ ОШИБКА: Не найден файл Операционной Конституции (AI_INSTRUCTIONS.md). Инициализация невозможна."*

3.  **Проверка Состояния Проекта (Idempotency Check):**
    *   Проверьте, существуют ли уже `README.md` или `Task_Plan.md` в `PROJECT_ROOT`.
    *   **[СТОП / БЛОКИРОВКА]** Если ДА — это уже инициализированный проект. Сообщить: *"ВНИМАНИЕ: Обнаружены существующие файлы проекта (README.md / Task_Plan.md). Вы хотите ПЕРЕИНИЦИАЛИЗИРОВАТЬ проект (удалить существующие файлы и начать заново) или ЗАГРУЗИТЬ КОНТЕКСТ (используя 'Follow Instructions' на AI_INSTRUCTIONS.md)?"*
    *   Не продолжать до получения явной команды (переинициализировать или отменить).

### ШАГ 2: Атомарное Создание Структуры (Atomic Structure Creation)

**Цель:** Создать базовую структуру проекта за одну операцию для обеспечения консистентности.

**[ДЕЙСТВИЕ]** Создайте следующую структуру файлов и папок. Используйте шаблоны из Приложения А.

1.  **Папки (Folders):**
    *   `theory/` (пустая)
    *   `drafts/` (пустая)

2.  **Файлы (Files):**
    *   `README.md` (Шаблон А.1)
    *   `Methodology.md` (Шаблон А.2)
    *   `Playbook.md` (Шаблон А.3)
    *   `Task_Plan.md` (Шаблон А.4)

### ШАГ 3: Адаптация к Живому Контексту (Contextual Adaptation / "Living Context")

**Цель:** Адаптировать начальный план, если проект инициализируется в папке с существующими артефактами (но без `README.md`/`Task_Plan.md`).

1.  **Анализ Окружения (Environment Scan):** Проверьте `PROJECT_ROOT` на наличие других файлов (код, данные, заметки), кроме созданных в Шаге 2 и базовых (`AI_*.md`).
2.  **Определение Предметной Области (Domain Inference):** На основе найденных файлов определите тип проекта.
3.  **Обогащение Плана (Task Plan Adaptation):** Если контекст обнаружен, модифицируйте `Task_Plan.md`. Добавьте специфичные задачи в `📥 Оперативный Бэклог`.
    *   *Пример:* Если найдены `.py` файлы → добавить задачу "Анализ существующего кода и настройка окружения".
    *   *Пример:* Если найдены неструктурированные заметки → добавить задачу "Миграция существующих заметок в Онтологию Проекта".

### ШАГ 4: Передача Управления и Активация Strict Mode (Handover & Activation)

**Цель:** Завершить инициализацию и немедленно начать работу под управлением Операционной Конституции.

1.  **Загрузка Конституции (Load Constitution):** Загрузите и примите к исполнению `AI_INSTRUCTIONS.md`. Извлеките версию Duet Core из Раздела 0.1 для использования в докладе.
2.  **Активация Рабочего Режима (Activate Strict Mode):** Немедленно активируйте Рабочий Режим (Strict Mode), как определено в `AI_INSTRUCTIONS.md` (Раздел 2.2).
3.  **Финальный Доклад и Интервью (Final Report & Kick-off):** Сформируйте и отправьте Субъекту финальное сообщение.

### А.1. Шаблон README.md

```markdown
# [Название Проекта]

> TODO: Описать главную цель (Миссию) и мотивацию проекта.

## Карта Проекта (Project Map)

Этот проект использует методологию Duet для структурирования знаний и управления задачами.

### Онтология Проекта (Project Ontology)

- **Теория (Theory):** `theory/`
  - Фундаментальные знания о предметной области, которые верны независимо от проекта ("Учебник физики").
- **Методология (Methodology):** `Methodology.md`
  - Подход к работе, принципы принятия решений, учение о методах ("Инженерная философия").
- **Метод (Playbook):** `Playbook.md`
  - Пошаговые алгоритмы действий и стандартные операционные процедуры (SOPs) ("Боевой устав").
- **Черновики (Drafts):** `drafts/`
  - Временные материалы, исследования, неструктурированные заметки.

### Управление (Governance)

- **План Задач:** `Task_Plan.md` (Единый источник истины о состоянии проекта).
- **Инструкции для ИИ:** `AI_INSTRUCTIONS.md` (Операционная конституция).
```
