# Skill: LecturesDigitizer

Оцифровка записи лекции через Gemini Gem → структурированный конспект.

**Trigger:** `оцифруй лекцию`, `lectures-digitizer`, `конспект лекции`

---

## Обзор

Агент нарезает аудио на чанки и готовит всё для работы с Gemini Gem.
Пользователь сам работает с Gem на gemini.google.com — загружает чанки и копирует результаты в подготовленные файлы. Агент затем склеивает конспекты в единый документ.

## Константы

```
SCRIPTOR_ROOT = <определить через workspace_info: найти stream "ТехноЛаб" → product "Scriptor" → main_folder>
GEM_INSTRUCTION = SCRIPTOR_ROOT/LecturesDigitizer/gem_instruction.md
MEDIA_DIR = <директория входного медиафайла>
OUTPUT_DIR = MEDIA_DIR/{name}/
DIGEST_DIR = OUTPUT_DIR/digest/
```

---

## Процедура

### Шаг 0: Инициализация

1. Спросить пользователя:
   - **Путь к медиафайлу** (если не указан в сообщении)
2. Определить `{name}` из имени медиафайла (без расширения).
3. Создать `OUTPUT_DIR` и `DIGEST_DIR`.
4. Проверить наличие `ffmpeg` в PATH.

### Шаг 1: Конвертация в mp3

```bash
ffmpeg -i "{input}" -vn -ac 1 -ar 16000 -ab 128k "{OUTPUT_DIR}/audio.mp3"
```

- Показать пользователю длительность через `ffprobe`.
- **Кэширование:** если `audio.mp3` уже существует — пропустить.

### Шаг 2: Нарезка на чанки

Параметры: `chunk_duration=20мин`, `overlap=30сек`.

```bash
ffmpeg -i "{audio.mp3}" -ss {start} -to {end} -c copy "{OUTPUT_DIR}/chunks/chunk_{NNN}.mp3"
```

- Если длительность ≤ 20 минут — один чанк, просто скопировать.
- **Кэширование:** если папка `chunks/` уже содержит файлы — пропустить.
- Показать пользователю список чанков с временными диапазонами.

### Шаг 3: Подготовка файлов для вставки

Создать пустые файлы для каждого чанка:

```
DIGEST_DIR/chunk_000.md   ← вставить конспект чанка 0
DIGEST_DIR/chunk_001.md   ← вставить конспект чанка 1
...
```

Каждый файл содержит только заголовок-подсказку:
```markdown
<!-- Вставь сюда конспект chunk_NNN от Gemini Gem -->
```

### Шаг 4: Инструкция для пользователя ⏸️

Вывести на экран следующее сообщение:

---

**Чанки готовы.** Теперь нужно поработать с Gemini Gem.

**Если Gem "LecturesDigitizer" уже создан** — переходи сразу к пункту 3.

**Если Gem ещё не создан** — скажи мне «как создать Gem», я объясню пошагово.

1. Открой → https://gemini.google.com (нужен аккаунт Google)
2. Перейди в свой Gem «LecturesDigitizer»
3. Загрузи все чанки из папки: `{OUTPUT_DIR}/chunks/`
4. Напиши Gem: **«начинай»**
5. После каждого чанка пиши: **«дальше»**
6. Копируй ответы в файлы: `{DIGEST_DIR}/chunk_000.md`, `chunk_001.md`, ...

Когда всё скопируешь — скажи мне **«готово»**, я соберу финальный конспект.

---

**СТОП. Ждать ответа пользователя.**

Если пользователь говорит «как создать Gem» или что Gem ещё не создан — дать следующую инструкцию:

```
Создание Gem на gemini.google.com:

1. Открой https://gemini.google.com
2. В левом меню нажми «Gems» → «Создать Gem» (или «New Gem»)
3. Название: LecturesDigitizer
4. В поле «Инструкции» вставь содержимое файла:
   {GEM_INSTRUCTION}
5. Нажми «Сохранить»

Gem готов. Теперь открой его, загрузи чанки из папки:
   {OUTPUT_DIR}/chunks/
...и напиши «начинай».
```

После этого снова ждать команды «готово».

### Шаг 5: Склейка в финальный документ

После команды «готово»:

1. Прочитать все файлы `DIGEST_DIR/chunk_NNN.md` по порядку.
2. Проверить что все файлы заполнены (не содержат только комментарий-заглушку).
3. Склеить в `OUTPUT_DIR/digest.md`:
   - Убрать дубликаты на стыках чанков (перекрытие ~30 сек).
   - Добавить единый заголовок `# {name}` в начало.
   - Сохранить структуру разделов: «Основные идеи», «Термины и определения», «Примеры».
   - Объединить термины из всех чанков в единый раздел в конце документа.
4. Сообщить: `Готово! Конспект: {name}/digest.md`

---

## Кэширование

- `audio.mp3` и `chunks/` кэшируются между запусками.
- `digest/` — не кэшируется, перезаписывается при новом запуске.

## Обработка ошибок

- **ffmpeg не найден** → `brew install ffmpeg`
- **Файл digest/chunk_NNN.md пустой** → напомнить пользователю заполнить его перед сборкой
