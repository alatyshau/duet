# Platform — Ручное тестирование

Код в этой папке **не покрывается автотестами** — Playwright не видит системный трей.

## Перед изменением

⚠️ **Правило:** Перед изменением любого файла в `platform/` — ручной тест на Mac + Windows.

## Чеклист проверки

### macOS

- [ ] Иконка появляется в Menu Bar
- [ ] При статусе `ready` — обычная иконка
- [ ] При статусе `no_config` или `path_lost` — warning иконка
- [ ] Клик по иконке открывает окно
- [ ] Правый клик (или обычный клик) показывает меню:
  - [ ] "Открыть Duet" — открывает окно
  - [ ] "Запускать при старте" — чекбокс работает
  - [ ] "Выйти" — закрывает приложение
- [ ] Tooltip правильный для каждого статуса
- [ ] Автозапуск: перезагрузить Mac, проверить что Duet запустился

### Windows

- [ ] Иконка появляется в System Tray
- [ ] При статусе `ready` — обычная иконка
- [ ] При статусе `no_config` или `path_lost` — warning иконка
- [ ] Клик по иконке открывает окно
- [ ] Правый клик показывает меню:
  - [ ] "Открыть Duet" — открывает окно
  - [ ] "Запускать при старте" — чекбокс работает
  - [ ] "Выйти" — закрывает приложение
- [ ] Tooltip правильный для каждого статуса
- [ ] Автозапуск: перезагрузить Windows, проверить что Duet запустился

## Ресурсы

Иконки находятся в `resources/tray/`:
- `mac/` — PNG файлы с суффиксом Template для macOS
- `win/` — ICO файлы для Windows
