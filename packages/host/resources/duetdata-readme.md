# DuetData

> Generated by Duet Host. Do not edit.

Local cache directory for [Duet](https://github.com/anthropics/duet) — knowledge and task management system.

## Structure

| Directory | Purpose |
|-----------|---------|
| `backend/` | Deployed Python HTTP API + MCP server |
| `repos/` | Cloned git repositories (products, instructions) |
| `data/` | JSON cache files (scan, streams, errors) |
| `.pid` | Backend process PID file |
| `duet-instructions.md` | Merged AI instructions (bootstrapper + user core) |

## Files in `data/`

| File | Source | Purpose |
|------|--------|---------|
| `scan.json` | `POST /scan` | Entity scan results |
| `streams.json` | `GET /streams` | Streams hierarchy cache |
| `duet-instructions-errors.json` | `POST /merge-duet-instructions` | Instruction validation errors |

## Notes

- This directory should be on a **fast local disk** (SSD), not in cloud storage.
- The `backend/` folder is managed by Duet Host deploy — do not modify manually.
- Git repositories in `repos/` are cloned by the backend scanner.
