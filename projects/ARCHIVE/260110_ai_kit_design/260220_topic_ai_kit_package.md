# Пакет ai-kit — организация

**Статус:** Снято. Пакет существует, решения реализованы.
**Откуда:** `260110_ai_kit_design/topic_ai_kit_package.md`

---

## Суть

Организация пакета `packages/ai-kit/` — набора инструментов для работы с AI.

## Ключевые решения

**Переименование ai-roles → ai-kit.** Название `ai-roles` не отражало scope: не только роли, но инструкции, скрипты, workflows, схемы.

**find_repo_root()** — скрипты ищут `.git` для определения корня репозитория. Работают независимо от расположения пакета.

**Разделение source/destination:**

| Папка | Режим | Использование |
|-------|-------|---------------|
| `packages/ai-kit/` | Разработка | Исходники — templates, scripts |
| `.ai/` | Использование | Сгенерированные артефакты для AI |

AI никогда не читает инструкции из `packages/ai-kit/`, только из `.ai/`.

**IGNORED_PREFIXES** — `.ai/` и `drafts/` фильтруются из backlog Keeper.

**Стандартизация _DOC полей** — массовая замена в 12 JSON, 5 Python, 3 схемах.

## Эволюция

Пакет прошёл через несколько редизайнов. К моменту архивации `packages/ai-kit/` трансформировался в `packages/ai-instructions/` с другой структурой (standalone .md вместо Jinja2 шаблонов). MCP стал отдельным `packages/backend/`.
