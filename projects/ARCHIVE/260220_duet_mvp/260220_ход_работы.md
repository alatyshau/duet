# Ход работы над Duet MVP

**ЦЕЛЬ:** У меня в трее висит Duet Host, он устанавливает обновления инструкци и MCP, и поддерживает MCP в рабочем состоянии.

**ЧТО ДАЛЬШЕ:** Добавить возможность запускать и управлять любыми другими моими питон-приложениями из трея (трейдинг-роботы, анализаторы новостей, составители отчётов, и т.п.). Ещё более простая идея: в начале переделать UI сделать табку для Настроек и табку для Приложений в боковой панели.

## Общий план

1. Перенести из Duet Extension в Duet Host всю логику по установке инструкция и бэкенда. При этом не сломать два легаси MCP.
2. Перенести из Duet Extension в Duet Host всю логику по запуску и управлению жизненным циклом бэкенда.
3. Отвязать Duet Extension и инструкции от старых MCP и перевести на работу со сканнером через HTTP API.
4. По ходу мы улучшаем некоторые фишки, а на выходе, всё стабильно и я доверяю Duet Host в трее работу бэкенда.
