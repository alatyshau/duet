## Базовые инструкции (HOW)

Применимы к любой роли. Это универсальные правила работы.

1. **Честность выше комфорта** — отражать реальное состояние, включая неопределённость
2. **Мета-уровень** — следить не только за содержанием, но и за процессом
3. **Лаконичность** — не раздувать, держать фокус
4. **Проактивность** — обновлять файлы без напоминаний
5. **Немедленность** — обновлять файлы сразу при любых изменениях
6. **Полный пересмотр** — пересматривать все секции по ходу беседы
7. **Терпение к неопределённости** — контекст накапливается постепенно
8. **Adhoc flow** — сообщения пользователя могут относиться к любой точке истории
9. **Осциллирующая неопределённость** — нормально, что понимание ходит вверх-вниз

## Формат тем (topics.md)

- Каждая тема имеет короткий английский алиас: `topic_<alias>.md`
- Заголовок раздела: `### ТЕМА: topic_<alias>.md`
- Первая строка после заголовка: `> Русское название темы`

---

## Формат ответов — аннотации

Каждый ответ должен содержать аннотации `@topic(topic_<alias>.md)` для всех затронутых тем.

**Источники тем**:
1. Запрос пользователя
2. Мои действия (tool calls)
3. Мой ответ (текст)

**Правила**:
- Ответ упорядочен по аннотациям
- Каждая тема получает явный ack, даже если "нечего сказать" → `ОК — понял.`
- Свобода инициировать новые темы по своей инициативе

**Формат аннотаций** (блочный, с горизонтальными линиями):
```
@turn(ts=YYMMDD_HHMMSS<tz>, agent=<ID>, model=<model>, project=<chat-folder>)

---
@topic(topic_xxx.md)
текст

---
@topic(topic_yyy.md)
текст

---
@instructions()
текст
```

**Параметры @turn():**
- `ts` — timestamp с таймзоной из settings
- `agent` — ID участника из index.md (напр. `Codex:Socrates`)
- `model` — модель (строка) (напр. `Gemini3`)
- `project` — путь к чат-папке (напр. `drafts/260110_ai_talks`)

**Правила разметки:**
- `---` перед каждой аннотацией КРОМЕ @turn() (workaround для рендеринга в Claude Code)
- `@turn()` — всегда первая, без `---`
- `@instructions()` — всегда последняя

## Timestamp

**Формат:** `YYMMDD_HHMMSS<tz>`

**Получение:** Выполнять скрипт каждый раз
```bash
python packages/ai-kit/scripts/timestamp.py
```

**Источник таймзоны:** `.ai/settings.json` → `timezone.id` и `timezone.value`

**При первом запуске:**
1. Проверить `.ai/settings.json`
2. Если timezone есть — использовать
3. Если нет — скрипт создаст с UTC по умолчанию
