## User Patterns

### How questions were asked
- **Прямые и конкретные** — каждый вопрос имел чёткую цель
- **Итеративное углубление** — от простого ("как сделать глобальный файл") к сложному ("как организовать 20 файлов с профилями")
- **Валидация понимания** — "Аа то есть я могу...", "Понял", "Ладно"
- **Сравнительные вопросы** — "А есть похожая система в Copilot?"
- **Проверка границ** — "А можно как-то переключаться...", "А он сможет хотя бы..."

### What worked well
- Краткие подтверждения ("Понял") давали сигнал двигаться дальше
- Раскрытие собственного контекста (AI-Kit с 20 файлами) позволило дать точные рекомендации
- Вопросы строились на предыдущих ответах — не было повторений
- Прагматичный подход: "Ладно для копилота будет без профилей" — быстрое принятие ограничений

### What didn't work
- Ничего критичного не сломалось
- Небольшая неопределённость в начале: вопрос был про "vs code" но на самом деле про Claude Code CLI — уточнилось само собой
