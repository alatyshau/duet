## Живые идеи

### 1. Пользовательская документация

Базовые инструкции (для агента) ≠ User guide (для человека). Нет документации "как пользоваться ai-instructions":

| Файл | Аудитория | Содержание |
|------|-----------|------------|
| README.md | Новый пользователь | Что это, для кого, quick start |
| docs/USAGE.md | Пользователь | Персоны, режимы, skills, workflows |
| docs/GLOSSARY.md | Все | Тезаурус: проект, дело, продукт, предприятие |

Как версионировать ai-instructions? Сейчас — git commits, но нет семантики версий. Вопрос станет актуальным при масштабировании на другие проекты.
