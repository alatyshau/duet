# Проверка зависимостей AI Kit

**Статус:** в работе

---

## МОТИВАЦИЯ

AI Kit использует MCP сервер на Python для предоставления инструментов (timestamp и др.).

Для работы MCP сервера нужны:
- Python 3.10 или выше
- Пакет `mcp`

Пользователь не должен разбираться в Python — всё должно настраиваться автоматически.

## ВЫХОДЫ

### Текущее решение: install.py

Пока расширение не умеет настраивать Python-окружение, используется скрипт:

```bash
python3 install.py -o ~/DuetData/ai-kit
```

Скрипт:
1. Проверяет Python 3.10+
2. Создаёт venv в `~/DuetData/.venv/`
3. Устанавливает `mcp` в venv
4. Копирует файлы AI Kit
5. Настраивает Claude Code (если установлен)

### Целевое решение: расширение

Расширение Duet при активации должно:
1. Проверить наличие `~/DuetData/.venv/`
2. Если нет — показать кнопку "Setup Python Environment"
3. По нажатию — выполнить те же шаги что install.py

### Почему venv?

Современные Python (3.12+) запрещают глобальную установку пакетов (`pip install mcp`). Это PEP 668 — защита системы от конфликтов. Поэтому создаём изолированное окружение.

### Структура после установки

```
~/DuetData/
├── .venv/                  # Изолированное Python-окружение
│   └── bin/python3         # Используется в settings.json
└── ai-kit/
    └── mcp-server/
```

### Если Python слишком старый

Показываем готовый промпт для AI-агента:

```
My 'python3' points to Python 3.9
I need it to point to Python 3.10+
Help me fix my PATH
```
