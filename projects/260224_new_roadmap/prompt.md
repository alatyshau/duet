## Процесс

1. Прочитай живые файлы — начни с index.md каждой папки
2. Сгруппируй по смыслу: что тянется к одной миссии?
3. Предложи новую структуру (папка = миссия, критерий завершения)
4. Получи одобрение
5. Перенеси файлы, создай index.md новых папок, удали опустевшие

---

## Правила

- **Один чат = один проект** — за одну сессию формируем только один новый проект из хламушника
- **Не дроби мелко** — лучше 1 проект с 3 топиками, чем 3 по 1
- **Не создавай "на вырост"** — только под реальный бэклог
- **Служебные файлы** (`draft_.md`, `init_prompt.md`, `instructions.md`, `temp/`, `use_cases/`, `web_use_cases/`) — разобрать отдельно: архив или удаление
- **Не действуй без одобрения**
