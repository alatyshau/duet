### 1\. Может ли ИИ работать с однофайловыми БД (DuckDB, SQLite)?

**Ответ: ДА, и это Game Changer.**

*   **Как это работает с ИИ:**

### 1\. Решение проблемы №5: Паттерн "Якорь и Тень" (Anchor & Shadow)

Чтобы связать "сухую цифру" (CSV) и "живую мысль" (MD), тебе нужен **Уникальный Идентификатор (ID)** как мост.

У тебя есть два слоя реальности:

**Слой А: Реестр (CSV)** — _Левое полушарие (Логика)_ Файл `projects.csv`:

```
id, name, status, deadline, priority
prj_01, "Разработка робота", "In Progress", 2025-12-01, High
prj_02, "Доклад по ИИ", "Draft", 2025-10-30, Medium
```

**Слой Б: Нарратив (Markdown)** — _Правое полушарие (Творчество)_ Файловая структура:

```
/10_Dialectic
    /projects
        /prj_01_Разработка_робота.md  <-- Это "Тело"
        /prj_02_Доклад_по_ИИ.md
```

**Как это работает (Магия Python/Макросов):**

1.  **Генерация:** Ты добавляешь строку в CSV. Твой Python-скрипт (слушающий изменения или запускаемый вручную) видит новый `id` и автоматически создает пустой MD-файл по шаблону в нужной папке.
2.  **Связь:** DuckDB, когда ты делаешь запрос, делает `JOIN` между данными из CSV и содержимым MD-файла (парся его как текст).
3.  **Навигация:** В VS Code ты настраиваешь (или просишь ИИ) быстрый переход: кликнул на ID в CSV — открылся MD файл.

**Итог:** CSV хранит метаданные (даты, статусы, цифры), MD хранит размышления. Они связаны через имя файла или Frontmatter заголовок внутри MD.
