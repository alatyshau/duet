---

## Живые идеи

### 1. AI Setup Wizard
UI в боковой панели Duet для настройки разных AI-агентов. Каждый AI (Claude Code, Copilot, Cursor) требует своей процедуры — расширение должно помогать с этим.

Концепция: секция "AI НАСТРОЙКА" с кнопками [Setup] для каждого агента, проверка статуса подключения (настроен / частично / не настроен).

### 2. Bootstrap для других AI
Claude Code решён через output styles. Copilot (Custom Agents) и Cursor (`.cursorrules`) — не реализованы. Нет универсального API для extensions.

### 3. find_entity по имени
Текущие MCP tools дают `streams`/`projects` (навигация по дереву), но нет поиска по имени. Может быть полезно для AI-агентов.

### 4. Формализация "трёх контекстов путей"
Три контекста путей (ai-kit root, относительные markdown, от корня workspace) — выявлены, но не формализованы в инструкциях как отдельная секция.
