## МОТИВАЦИЯ

Сейчас Sidebar имеет плоскую структуру: Установка, секция Приложения, AI Агенты — всё вперемешку. Когда появятся пользовательские Python-приложения, нужно чёткое разделение: одна зона для настройки Host, другая — для управления приложениями.

Это первый шаг перед добавлением произвольных Python-приложений — подготовить UI.

## НАРРАТИВ

### Текущее состояние (260224)

```
Sidebar:
  [Открыть DuetData]
  Установка          ← topItem
  ▼ Приложения       ← section
    ● Duet Backend
  AI Агенты          ← bottomItem
```

Три разных элемента навигации (topItem, section, bottomItem) без явной группировки. При добавлении новых приложений секция "Приложения" вырастет, а "Установка" и "AI Агенты" останутся разрозненными.
