# Duet

> **Мост между Человеком и Машиной. Великая Встреча двух Стихий.**

**Duet** — это проект, посвященный исследованию, формализации и развитию протоколов взаимодействия между Субъектом (Человеком, носителем Воли и Риска) и Интеллектом (ИИ, носителем Вычисления и Кристаллизации).

> *"Quine в мире менеджмента"* — проект, который описывает сам себя и используется для своего же развития.

## 🎯 Миссия
Создать идеальный интерфейс сотрудничества, где Человек не тратит энергию на микроменеджмент, а ИИ не галлюцинирует и действует строго в рамках интенции, обеспечивая максимальную интеллектуальную честность и эффективность.

## 🗺 Карта Проекта

### Ядро
*   **`AI_INSTRUCTIONS.md`** — **Сердце проекта.** "Боевой устав" для AI. Содержит все активные протоколы (Онбординг, Интеллектуальная Честность, Управление Задачами и др.). Это тот файл, который скармливается агенту в начале сессии.

### Структура Знаний
*   **`theory/`** — **Теория и Философия.**
    *   Фундаментальные принципы взаимодействия (Кибернетика, Теория Агентов).
    *   Определения ролей: Субъект vs Интеллект.
*   **`Methodology.md`** — **Методология.**
    *   Как мы создаем промпты?
    *   Как мы тестируем протоколы?
    *   Принципы эволюции `AI_INSTRUCTIONS.md`.
*   **`Playbook.md`** — **Боевой Устав.**
    *   Стандартные Операционные Процедуры (SOP) для Оператора и AI.
    *   Алгоритмы управления задачами, инцидентами и знаниями.
*   **`src/*`** — **Исходный код**
    *   Промпты с инструкциями для AI.

### Управление
*   **`Task_Plan.md`** — Живой документ для синхронизации текущего контекста и задач.
*   **`drafts/`** — Рабочая зона для сырых диалогов и идей.
