# settings.local.json

ЧТО: Локальные настройки Claude Code для этого репозитория.
ЗАЧЕМ: Хранит разрешения (permissions), которые пользователь дал Claude Code.
КТО ИСПОЛЬЗУЕТ: Claude Code CLI автоматически читает при запуске.

---

## Важно

**Этот файл генерируется автоматически** системой Claude Code.
Не редактируй вручную — используй интерфейс Claude Code для управления разрешениями.

---

## Поля

### permissions.allow

Массив паттернов команд, которые Claude Code может выполнять без дополнительного подтверждения.

**Формат паттерна:** `Tool(command:args)`

**Примеры:**
- `Bash(cd:*)` — разрешить cd в любую директорию
- `Bash(git log:*)` — разрешить git log с любыми аргументами
- `Read(/path/**)` — разрешить чтение файлов в директории
