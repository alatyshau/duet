# Настройка AI Kit

## settings.json

Файл `settings.json` содержит пользовательские настройки AI Kit. Создаётся автоматически при первом билде с дефолтными значениями (UTC).

**Расположение:** `{DuetData}/ai-kit/settings.json`

### Структура

```json
{
    "timestampTZ": {
        "id": "M",
        "value": "Europe/Moscow"
    }
}
```

### Настройки

#### timestampTZ

Таймзона для генерации timestamp в формате `YYMMDD_HHMMSS<tz>`.

| Поле | Описание | Пример |
|------|----------|--------|
| `id` | Короткий код (1-2 символа) — добавляется к timestamp | `M` |
| `value` | IANA timestampTZ name | `Europe/Moscow` |

**Примеры таймзон:**

| Город | id | value |
|-------|-----|-------|
| Москва | `M` | `Europe/Moscow` |
| UTC | `Z` | `UTC` |
| Нью-Йорк | `E` | `America/New_York` |
| Лос-Анджелес | `P` | `America/Los_Angeles` |
| Лондон | `L` | `Europe/London` |
| Токио | `T` | `Asia/Tokyo` |

### Пример: настройка московской таймзоны

1. Откройте файл `settings.json` в вашей AI Kit директории
2. Замените содержимое на:

```json
{
    "timestampTZ": {
        "id": "M",
        "value": "Europe/Moscow"
    }
}
```

3. Сохраните файл

Теперь timestamp будет генерироваться в московском времени: `260126_231500M`

### Примечания

- Файл сохраняется при переустановке (`install.py` не перезаписывает существующий)
- Если файл удалён, при следующей установке создастся дефолтный (UTC)
- MCP сервер читает настройки автоматически при каждом вызове
