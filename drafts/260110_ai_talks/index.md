**Продукт**: Формат topic-файлов для базовых инструкций.

### ТЕМА: topic_context_persistence.md
> Механизм персистентности шагов

**Статус**: В работе — спецификация готова @turn(260112_004445M).

**Суть**: State machine для шагов внутри секции ПЛАН ВНЕДРЕНИЯ. Защита от "вылетания вперёд".

**Ключевые решения:**
- State machine: `TODO → WIP → IN_REVIEW → DONE`
- Команды: `/next`, `/done`, `/done-next`
- Правило: междометия ("хорошо", "ок") ≠ команда
- WIP обычно один, IN_REVIEW может быть много
- Формат шага: H3 + статус + "Ход работы"

**Продукт**: Правила для базовых инструкций.

### ТЕМА: topic_base_instructions.md
> Разработка базовых инструкций (CLAUDE.md)

**Статус**: В работе — шаги 1-5 выполнены (шаг 4 принят @turn(260112_191500M), шаг 5 принят @turn(260112_202853M)); следующий — шаг 6.

**Цель**: Написать INSTRUCTIONS.md.j2 → генерирует CLAUDE.md, GEMINI.md и т.д.

**Ключевые решения @turn(260112_010109M):**
- 4 режима агента: Диалог, Secretary, Планирование, Execute
- Иерархия: Чат-папка (проект) → Topic-файл (под-проект) → Шаги
- Правило: Execute только с планом
- В режиме Диалог фокус на index.md (экономия токенов)

**Ключевые решения @turn(260112_014515M):**
- `mode=` в @turn() — агент объявляет режим в первой аннотации
- Начало сессии = DIALOGUE (даже если есть WIP в файлах)
- Один результирующий файл (j2 собирает из модулей)
- Структура templates/ по секциям инструкций (см. topic-файл)

**Ключевые решения @turn(260112_125015M):**
- **Режим = единственная ось контроля** "что происходит и что разрешено"
- "Процедура" как отдельное понятие не нужна
- **Роль** (КТО, с именем) ≠ **Режим** (ЧТО, без имени)
- Роли называем именами: Socrates, Hermes, Daedalus, Hephaestus, Loki
- Режимов может быть много: DIALOGUE, PLANNING, EXECUTE, SECRETARY, COMMENTARY, KEEPER, TRICKSTER
- **Default = DIALOGUE**: все роли стартуют в DIALOGUE, специализация — не default

**Ключевые решения @turn(260112_163018M):**
- **Формат @turn() упрощён**: `agent=Сократ` (только имя, без client/model)
- **Несколько агентов одной роли допустимо**: разные проекты, параллельная работа
- **Параллельное ревью**: "совет мудрецов" — разные роли/модели ревьюят одно

**Ключевые решения @turn(260112_163139M):**
- **Формат комментариев**: `::: Сократ (Cursor@Opus) :::` — полная атрибуция
- **Structured debate**: споры прямо в документе (use case для COMMENTARY)

**Зависимости:**
- topic_document_structure.md — структура чат-документов
- topic_context_persistence.md — state machine шагов

**Продукт**: `packages/ai-kit/templates/INSTRUCTIONS.md.j2`
