# Архитектура системы

## Компоненты

Система состоит из трёх модулей: Auth, API, Storage.

- ::: АЛ ::: мой коммент К001 (начинается тред комментов)
  - это первая вложенная строчка моего коммента К001
    - ::: ИИ ::: коммент К002 ИИ к первой строчке коммента К001 от АЛ
      - ИИ решил тоже в несколько строчек написать свой коммент К002
        - ::: АЛ ::: коммент К007 к первой строчке коммента К002
          - строчка 1 коммента К007
      - вторая строчка ИИ-коммента К002
      - третья строчка ИИ-коммента К003
    - ::: АЛ ::: коммент К003 от АЛ в треде начатому комментом К002
      - первая строчка коммента К003
      - вторая строчка коммента К003
      - третья строчка коммента К003
  - это вторая строчка моего коммента К001
- ::: ИИ ::: коммент К004 от ИИ в треде начатому комментом К001
  - первая строчка коммента К004
  - вторая строчка коммента К004
- ::: АЛ ::: коммент К005 в треде начатому комментом К001 (логически идёт после К004, но может аппелировать ко всем комментам в треде выше)
