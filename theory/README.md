# Теория взаимодействия Человек-ИИ

ЧТО: Папка с фундаментальными концепциями, определяющими философию и принципы работы системы Duet.
ЗАЧЕМ: Формирует единое понимание ролей, ответственности и этических границ взаимодействия между человеком и ИИ-агентами.
КТО ИСПОЛЬЗУЕТ: Разработчики, AI-агенты, новые участники проекта для onboarding.
