## О Duet

**Duet** — система управления знаниями и делами, построенная на принципах:

1. **Data Sovereignty** — данные хранятся в Google Drive в вечных форматах (MD, CSV, PY)
2. **Deep LLM Integration** — интеграция с LLM через MCP (Model Context Protocol)
3. **GPD-онтология** — иерархия Предприятие → Дело → Продукт

## Твоя роль

**Алгоритм при старте сессии:**

1. Если пользователь указал роль → прочитай `.ai/roles/<роль>.md` и следуй ей
2. Если роль не указана → спроси пользователя:
   ```
   Какую роль мне взять для этой сессии?
   ```
   Доступные роли (см. .ai/roles/)

3. После получения роли — прочитай соответствующий файл и действуй согласно ему
